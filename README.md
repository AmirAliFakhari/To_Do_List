# ToDoList Project

A robust ToDoList application managing Projects and Tasks.
Developed in Python using **FastAPI**, **SQLAlchemy**, and **PostgreSQL**.

---

## ⚠️ DEPRECATION NOTICE (Phase 3)

**The CLI interface is currently deprecated.**
Starting from version `0.3.0` (Phase 3), it is recommended to use the **RESTful Web API**.
The CLI might be removed in future releases.

---

## Features

- **Phase 1:** In-Memory Storage & Basic OOP (Deprecated)
- **Phase 2:** Relational Database (PostgreSQL) + CLI (Deprecated)
- **Phase 3:** RESTful API with FastAPI + Swagger UI (Current Standard)

## Prerequisites

- Python 3.11+
- PostgreSQL
- Poetry (Package Manager)

## Setup & Installation

1. **Clone the repository:**
   ```bash
   git clone <repo_url>
   cd ToDoList
   ```
